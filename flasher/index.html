Dune Weaver Flasher

Install the Dune Weaver firmware on an MKS DLC32 over USB, and set up WiFi and MQTT in the same step.

This browser can't flash boards

Flashing needs Web Serial. Use a desktop browser that has it: Chrome, Edge, or Firefox 151 or later.

Firefox lists the board as "USB Serial" rather than a COM port; pick that one. If the page sits on "Waiting for the board to boot…", press RESET on the board, or use Chrome or Edge.

1. Board and install

Fresh install erases everything on the board. Download a backup first (bottom of this page) if the board already runs Dune Weaver. Patterns on the SD card are not touched.

Setup only: changes the WiFi, MQTT, table name or config on a board that already runs Dune Weaver. No jumper or BOOT button needed. Leave "Table config" on "No table config" to keep the current one, and fill in only what you want to change. Passwords must be typed every time.

Getting the board into download mode. Most boards switch on their own. If flashing stops with "Failed to connect":

  • MKS DLC32 v2.2 (no BOOT button): short the SDA pin to GND with a jumper wire, press RESET, then press Connect again. Remove the short when flashing is done, or the board won't start.
  • Boards with a BOOT button: hold BOOT, tap RESET, release BOOT, then press Connect.
  • Only changing WiFi or MQTT? Tick "Don't flash" above instead; no jumper needed.

2. Table

Uploads a config.yaml for your table. A fresh install needs one; an update keeps the current config unless you pick one.

Prefilled from the table's config. The original Dune Weaver uses the Pro board with 287 steps and 75 LEDs.

3. WiFi and MQTT (optional)

WiFi: 2.4 GHz networks only (the ESP32 has no 5 GHz radio), password 8–63 characters.

These go to the board over USB only. This page doesn't save or send them anywhere else, and clears the password fields after a successful run (they stay filled in after a failure so you can retry).

4. Restore a backup (optional)

A backup from this page, a /sand_settings JSON file, or $Setting=value lines. Settings are restored after the table restarts. Passwords are never in backups, so enter them above.

Plug the board in over USB, then press Connect.

Back up a table over USB

Saves the table's settings and config.yaml to a file. Passwords are left out.
